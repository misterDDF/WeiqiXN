# Font Assets

Updated on 2026-09-28 for the V3 theme fonts (Source Han Sans CN Medium and Source Han Serif CN SemiBold).

All fonts are licensed under the SIL Open Font License 1.1. The license texts are kept next to the fonts as `LICENSE-SourceHanSans.txt` and `LICENSE-SourceHanSerif.txt`. The OFL lets the fonts be bundled with the game; the font files must not be sold on their own, and a modified font must not use the reserved name "Source".

The TMP font assets are generated by the menu `自定义功能/UI/生成主题字体资产`, using the same settings as Regular: dynamic, sampling size 90, padding 9, SDFAA, 1024 atlas with multi-atlas. Dynamic font assets include their source OTF in the `font` AssetBundle.
