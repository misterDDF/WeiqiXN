## 美术方向

**一句话**：一张真实的榧木棋盘放在素色麻布桌面上，旁边是几张和纸记录卡。

| 关键词 | 落到画面上的含义 | 反面（禁止） |
|---|---|---|
| 朴素 | 材料本色、低饱和、暖中性色；装饰只来自材料本身（木纹、石纹、纸纹） | 霓虹、发光、描金、泼墨、皮革、渐变按钮、游戏化图标 |
| 简约 | 元素少、颜色少、留白多；1px 细线分隔；一个强调色只用在最重要的地方 | 多套视觉语言并存、大面积高饱和色块、无意义的边框装饰 |
| 真实质感 | 物理材料（榧木、那智黑石、蛤碁石、和纸、麻布）+ 真实光影（软投影、接触阴影、棋盘在桌面上的落影）+ 真实声音 | 平涂无光照、阴影缺失、塑料感高光、果冻弹跳 |

参照物：实体棋具（榧木棋盘、蛤碁石白子、那智黑石黑子）、纸质棋谱与记录卡。相机保持正交俯视（2026-06-09 决策），“厚度”和“立体感”只能靠光影、落影和材质表达，不改相机。

### 字体

- 正文：思源黑体 SC，补 `Medium` 字重，替换当前 84 处 Regular 伪粗体。
- 标题/棋局名：思源宋体 SC `SemiBold`，只用于页面标题、对局结果等少量场景。
- 字号阶梯（1600×900 / 720×1280 参考分辨率共用）：`40 / 28 / 22 / 18 / 15`，不再使用 26.2、16.55 这类零碎字号。
- 数字（计时、目数、手数）使用等宽数字写法或固定宽度容器，避免跳动。

### 形与动

- 圆角 4–6px；描边 1px `Hairline`；阴影只用一层低不透明度柔影（纸卡落在桌面上的感觉）。
- UI 动效 160–240ms、ease-out；位移不超过 8px、缩放不超过 3%；不使用弹跳。
- 项目没有 tween 库，`Time.timeScale` 从不赋值；UI 动效用 `Time.unscaledDeltaTime`，写法参考 `UIPageTransition`。

## 用户反馈与取舍（跨阶段有效）

- 真实感优先。以下做法已被否决：实时软阴影（正交俯视下偏硬、像贴纸）、GGX 点高光（像台球）、Neutral 色调映射（整体发灰）。现用接触阴影面片、桌布解析落影、柔光窗反射，不做色调映射。
- 高光：大面积虚边光泽像污渍，小块硬边矩形像贴纸，都被否决。现为左上方小块柔边圆角反光，模糊按角度计。亮度参照（sRGB）：黑子约 36，白子中心约 211，棋盘约 238。
- 语义色不为统一色板而压暗：AI 推荐点用亮绿 `Hint`，黛青读成墨绿甚至蓝色，被否决。
- 盘上文字以移动端可读为先，宁大宁粗，不求精致。
- 已有动效沿用美化前手感。改动前先从 git 读出旧版本的幅度与节奏，不用新风格替换用户熟悉的效果。V2.1 摇晃约 4° 看不出，V2.2 上抬收缩“很奇怪”，都已改回。
- 纸色形势方块不描边，否则叠在白子上读成方框；深色半透明圆片会透出网格线，因此第一推荐点不透明。

## V1 场景与棋具（已完成）

细节见 `SPECIFICATION.md`、[08-board-and-rules.md](08-board-and-rules.md)、[10-editor-tools.md](10-editor-tools.md)。

- 渲染：MSAA 4x；不使用实时阴影。后处理只保留 Color Adjustments、White Balance 和极弱 Vignette，Tonemapping 为 None，无 Bloom。
- 棋盘：2048² 柾目榧木贴图按棋盘 UV 覆盖整盘。受光的 `Ground.shader` 解析绘制墨线与星位（`fwidth` 抗锯齿），`RoadMesh` 只保留碰撞体。
- 棋子：程序生成双凸透镜网格。`StoneGloss.shader` 用小面光源反射、SH 环境光和 Fresnel，黑子为那智黑，白子为蛤碁石。每颗棋子带接触阴影面片。
- 桌面与光：深色素麻桌布，`Table.shader` 解析盘体落影；主光仰角 62°，从左上方照下。
- 盘上标记：`BoardSurfaceMarker`、`BoardOverlay.shader` 与 TMP 绘制坐标、手数、胜率、推荐点、最后一手和形势方块。
- 美术参数由幂等编辑器菜单维护；`自定义功能/场景/生成对局画面预览截图` 在不进 Play 的情况下离屏截图对比（见 10 号文档）。
- 未确认项：Android 竖屏可读性，以及 Medium 质量档开启 MSAA 4x 后的帧率。

## 性能预算

- 目标：Android 中端机（Medium 质量档）稳定 60fps；PC 不低于当前。
- 阴影：不渲染实时阴影贴图；棋子接触阴影为每颗一张面片（乘法混合），盘体落影在桌布 shader 中解析计算；不加 SSAO。
- 后处理：只保留 Color Adjustments、White Balance、Vignette；Tonemapping 覆盖为 None。
- 贴图：棋盘 2048（Android 平台覆盖 1024、ASTC）；桌面 1024 平铺；白子条纹 512；UI 主题贴图尽量用小尺寸九宫格。
- Shader：棋盘、棋子、桌面均为单 pass 前向，仅主光 + SH 环境光；不使用额外灯光。
