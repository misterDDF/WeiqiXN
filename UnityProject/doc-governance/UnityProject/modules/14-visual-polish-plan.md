## 美术方向

**一句话**：一张真实的榧木棋盘放在素色麻布桌面上，旁边是几张和纸记录卡。

| 关键词 | 落到画面上的含义 | 反面（禁止） |
|---|---|---|
| 朴素 | 材料本色、低饱和、暖中性色；装饰只来自材料本身（木纹、石纹、纸纹） | 霓虹、发光、描金、泼墨、皮革、渐变按钮、游戏化图标 |
| 简约 | 元素少、颜色少、留白多；1px 细线分隔；一个强调色只用在最重要的地方 | 多套视觉语言并存、大面积高饱和色块、无意义的边框装饰 |
| 真实质感 | 物理材料（榧木、那智黑石、蛤碁石、和纸、麻布）+ 真实光影（软投影、接触阴影、棋盘在桌面上的落影）+ 真实声音 | 平涂无光照、阴影缺失、塑料感高光、果冻弹跳 |

参照物：实体棋具（榧木棋盘、蛤碁石白子、那智黑石黑子）、纸质棋谱与记录卡。相机保持正交俯视（2026-06-09 决策），“厚度”和“立体感”只能靠光影、落影和材质表达，不改相机。

### 字体

- 正文：思源黑体 SC Regular；强调用思源黑体 CN `Medium`，替换当前 84 处 Regular 伪粗体（伪粗体字距被撑开，Medium 更紧、笔画更匀）。
- 标题/棋局名：思源宋体 CN `SemiBold`，只用于页面标题、对局结果等少量场景。
- 字号以方案 E 为准。横屏：时钟 56、手数 44、页面标题 34、玩家名 28、操作 18、说明 13–14、眉题 13；竖屏：时钟 52、玩家名 26、手数 22、底栏 15。不再使用 26.2、16.55 这类零碎字号。
- 数字（计时、目数、手数）使用等宽数字写法或固定宽度容器，避免跳动。

### 形与动

- 圆角 4–6px；描边 1px `Hairline`；阴影只用一层低不透明度柔影（纸卡落在桌面上的感觉）。
- UI 动效 160–240ms、ease-out；位移不超过 8px、缩放不超过 3%；不使用弹跳。
- 项目没有 tween 库，`Time.timeScale` 从不赋值；UI 动效用 `Time.unscaledDeltaTime`，写法参考 `UIPageTransition`。

## 用户反馈与取舍（跨阶段有效）

- 真实感优先。以下做法已被否决：实时软阴影（正交俯视下偏硬、像贴纸）、GGX 点高光（像台球）、Neutral 色调映射（整体发灰）。现用接触阴影面片、桌布解析落影、柔光窗反射，不做色调映射。
- 高光：大面积虚边光泽像污渍，小块硬边矩形像贴纸，都被否决。现为左上方小块柔边圆角反光，模糊按角度计。亮度参照（sRGB）：黑子约 36，白子中心约 211，棋盘约 238。
- 语义色不为统一色板而压暗：AI 推荐点用亮绿 `Hint`，黛青读成墨绿甚至蓝色，被否决。
- 盘上文字以移动端可读为先，宁大宁粗，不求精致。
- 已有动效沿用美化前手感。改动前先从 git 读出旧版本的幅度与节奏，不用新风格替换用户熟悉的效果。V2.1 摇晃约 4° 看不出，V2.2 上抬收缩“很奇怪”，都已改回。
- 纸色形势方块不描边，否则叠在白子上读成方框；深色半透明圆片会透出网格线，因此第一推荐点不透明。
- UI 风格：旧 RPG 皮肤太花哨，平涂纸卡迁移太简陋。要的是“朴素高级感”：半透明层叠在场景上，靠字体层级、留白、细线和字距出效果。允许大改布局和交互，功能保持一致；页面动手前先出样张。
- 必须兼顾移动端竖屏：同一 prefab 用 StateRoot 的 `Landscape` / `Portrait` 两态，竖屏按移动端单独设计。
- 方案 D 横屏被否：右栏常态只靠底部操作撑着，上方大片空白；两位玩家同在一张纸上，分不清黑白。由此定下两条版式原则：每一栏上下两端都要有常驻内容压住；玩家按棋色分卡。竖屏排版获认可，横屏改为沿用竖屏结构（方案 E）。

## V1 场景与棋具（已完成）

细节见 `SPECIFICATION.md`、[08-board-and-rules.md](08-board-and-rules.md)、[10-editor-tools.md](10-editor-tools.md)。

- 渲染：MSAA 4x；不使用实时阴影。后处理只保留 Color Adjustments、White Balance 和极弱 Vignette，Tonemapping 为 None，无 Bloom。
- 棋盘：2048² 柾目榧木贴图按棋盘 UV 覆盖整盘。受光的 `Ground.shader` 解析绘制墨线与星位（`fwidth` 抗锯齿），`RoadMesh` 只保留碰撞体。
- 棋子：程序生成双凸透镜网格。`StoneGloss.shader` 用小面光源反射、SH 环境光和 Fresnel，黑子为那智黑，白子为蛤碁石。每颗棋子带接触阴影面片。
- 桌面与光：深色素麻桌布，`Table.shader` 解析盘体落影；主光仰角 62°，从左上方照下。
- 盘上标记：`BoardSurfaceMarker`、`BoardOverlay.shader` 与 TMP 绘制坐标、手数、胜率、推荐点、最后一手和形势方块。
- 美术参数由幂等编辑器菜单维护；`自定义功能/场景/生成对局画面预览截图` 在不进 Play 的情况下离屏截图对比（见 10 号文档）。
- 未确认项：Android 竖屏可读性，以及 Medium 质量档开启 MSAA 4x 后的帧率。

实现约束（后续改动需保持）：

- 共享材质上的动态效果一律用 `MaterialPropertyBlock`，到终值后 `SetPropertyBlock(null)` 保持合批。目前用于投影、预览透明度和最后一手圆点。
- 是否播放落子动画由调用方显式传参：只有新下的一手播放，所有按局面重建的路径直接显示。
- 编辑器截图不推进协程，所以从透明开始的运行时淡入只在 `Application.isPlaying` 时启动。截图菜单的 `board19_motion_closeup` 按落子关键帧采样。
- 弹窗过渡在运行时把 `CanvasGroup` GetOrAdd 到内容根上，prefab 零改动。遮罩按名称含 `mask` 识别，只淡入不位移；新增弹窗须遵守这一命名。

### 方案 E（2026-09-29 定稿）

样张和生成脚本在 [design/v3/](../design/v3/)。样张是方向稿，像素以实现为准。脚本读截图菜单输出的 `LookPreview` 底图，横屏棋盘靠左的底图由 `make_backdrop.py` 合成。

通用语言：

- 层次：半透明层叠在场景上。卡片用 `Paper` α 0.9，描边白 α 0.35；抽屉和弹窗用 `Paper` α 0.95。黑方墨卡为 `#12100E` α 0.86，描边 `Paper` α 0.10。遮罩为 `#0E0C0A` α 0.45，细线为墨或纸 α 0.12–0.14。圆角：卡片 6、按钮 4、底部抽屉顶角 18。阴影只用一层柔影。
- 桌面上的无框文字用纸色，按不透明度分四级：0.95 主文字、0.85 次要、0.5 眉题和说明、0.35 弱提示。
- 字体分工：宋体 SemiBold 用于手数、玩家名、时钟、页面标题和结果；黑体 Medium 用于眉题（字距 3–4）、按钮和操作名；Regular 用于说明。
- 按钮：主按钮墨底纸字；危险操作用朱色；次按钮为纯文字或细线框。朱色只用于行棋标记、危险操作、结果和红点；落在墨卡上时提亮为 `#CC6048`。
- 横竖屏：每页一个 prefab，`sr_platform` 上的 StateRoot 用 `Landscape` / `Portrait` 两态切换位置和尺寸，竖屏专有节点用 GameObjectActive 控制，业务代码只选状态。`DuelPage` 目前没有 `sr_platform`，需要新增。

对局页 `DuelPage`：

- 横屏（1600×900）：棋盘靠左，外框约 x 42–858。复盘页的相机横移在对局场景也启用，偏移到左边距等于上边距。右栏 x 906–1558，上下与棋盘对齐。自上而下依次是：
  - 白方卡，高 150。
  - 对局信息：眉题“模式 · 路数 · 贴目”，下面是宋体“第 N 手”。
  - 动态区。
  - 操作列表：4 行，每行 54，依次为虚手、形势、分析、对局菜单，右侧附灰字说明。
  - 黑方卡，高 150，与操作列表间隔 24。
- 竖屏（720×1280）：自上而下依次是：
  - 顶部状态行：左侧平时是对局信息，形势开启时换成形势结果，落子提示会临时覆盖；右侧是“第 N 手”。
  - 白方卡：x 14、宽 692、高 136。
  - 棋盘：约 y 295–985。
  - 黑方卡。
  - 底栏：四等分，依次为虚手、形势、分析、菜单。
- 玩家卡：固定按棋色，不按座位；横竖屏共用节点。内容：
  - 左侧：棋子 +“黑方”眉题 +“行棋中”，宋体名字，副标题。
  - 右侧：宋体时钟（非行棋方 α 0.3），下面是读秒说明。
  - 行棋方的卡片左缘有 3px 朱色竖条。
- 动态区：
  - 形势块只在形势开启时出现，先显示计算中，再显示结果。关闭形势或打开 AI 分析时清除。
  - 落子提示沿用 2.2s 显示、0.28s 淡出。
  - 两者自上而下堆叠，用 VerticalLayoutGroup，所以形势关闭时提示会顶到最上面。
  - 形势行的右侧说明：开启时是红点 +“已开启”，关闭时是“显示归属与目数”。
- 终局：横屏用结果卡替换对局信息和动态区。结果卡内容：眉题“终局 · 模式”、朱印“胜”、宋体“X 胜出”、结束原因，以及墨色“退出对局”按钮。虚手和分析置灰。竖屏终局未出稿。

  - 盘上显示朱色十字准线和半透明预览子。
  - 棋盘仍可点按、拖动，自动关闭条件不变。
- 其余状态按现有逻辑映射到新位置：
  - OGS 点目阶段：虚手行改为“不接受”，形势行改为“确认死子 / 等待对方确认”，倒计时放进动态区。

`ConfirmPopup`：横屏是居中的宣纸页，宽 600，眉题 + 宋体标题 + 正文或表格，按钮右对齐；竖屏是底部抽屉，按钮等分全宽。

`MainMenuPage`：

## 性能预算

- 目标：Android 中端机（Medium 质量档）稳定 60fps；PC 不低于当前。
- 阴影：不渲染实时阴影贴图；棋子接触阴影为每颗一张面片（乘法混合），盘体落影在桌布 shader 中解析计算；不加 SSAO。
- 后处理：只保留 Color Adjustments、White Balance、Vignette；Tonemapping 覆盖为 None。
- 贴图：棋盘 2048（Android 平台覆盖 1024、ASTC）；桌面 1024 平铺；白子条纹 512；UI 主题贴图尽量用小尺寸九宫格。
- UI 主题贴图：20 张，不压缩（RGBA32 含 mip）共约 1.4MB，已在 `ui_main_texture` 包中；若包体吃紧，V6 可打图集或改用单通道格式。
- 字体：动态字体会把源 OTF 打进包，V3.1 新增的两款字体共增加约 20MB（Medium 8.4MB、Serif 11.8MB）。Serif 只用于少量标题，V6 可改为静态图集，不再带源文件。
- Shader：棋盘、棋子、桌面均为单 pass 前向，仅主光 + SH 环境光；不使用额外灯光。
