# 视觉美化计划：朴素 · 简约 · 真实质感

## 文档定位

本文是 `WeiqiXN UnityProject` 全方位视觉美化的专门计划文档，统一描述美术方向、设计令牌、分阶段任务、性能预算和验收口径。

- 本文只描述视觉表现的目标、拆分和约束，不改变棋规、落子、提子、回合、存档、AI 或联机行为。
- 本文不替代 `SPECIFICATION.md`、`ARCHITECTURE.md`、`ROADMAP.md` 的权威职责；已落地的当前行为仍以 `SPECIFICATION.md` 和对应模块文档为准。
- UI prefab 修改仍必须遵守 [03-ui.md](03-ui.md) 与 `AGENTS.md` 中的 Canvas 根节点、`PanelRoot`、受保护布局节点和 StateRoot 规则。

## 美术方向

**一句话**：一张真实的榧木棋盘放在素色麻布桌面上，旁边是几张和纸记录卡。

| 关键词 | 落到画面上的含义 | 反面（禁止） |
|---|---|---|
| 朴素 | 材料本色、低饱和、暖中性色；装饰只来自材料本身（木纹、石纹、纸纹） | 霓虹、发光、描金、泼墨、皮革、渐变按钮、游戏化图标 |
| 简约 | 元素少、颜色少、留白多；1px 细线分隔；一个强调色只用在最重要的地方 | 多套视觉语言并存、大面积高饱和色块、无意义的边框装饰 |
| 真实质感 | 物理材料（榧木、那智黑石、蛤碁石、和纸、麻布）+ 真实光影（软投影、接触阴影、棋盘在桌面上的落影）+ 真实声音 | 平涂无光照、阴影缺失、塑料感高光、果冻弹跳 |

参照物：实体棋具（榧木棋盘、蛤碁石白子、那智黑石黑子）、纸质棋谱与记录卡。相机保持当前正交俯视口径（2026-06-09 决策），因此“厚度”和“立体感”只能通过光影、落影和材质表达，而不是改相机。

### 字体

- 正文：思源黑体 SC，补 `Medium` 字重，替换当前 84 处 Regular 伪粗体。
- 标题/棋局名：思源宋体 SC `SemiBold`，只用于页面标题、对局结果等少量场景。
- 字号阶梯（1600×900 / 720×1280 参考分辨率共用）：`40 / 28 / 22 / 18 / 15`，不再使用 26.2、16.55 这类零碎字号。
- 数字（计时、目数、手数）使用等宽数字写法或固定宽度容器，避免跳动。

### 形与动

- 圆角 4–6px；描边 1px `Hairline`；阴影只用一层低不透明度柔影（纸卡落在桌面上的感觉）。
- 动效 160–240ms、ease-out；位移不超过 8px、缩放不超过 3%；不使用弹跳。

## 现状诊断（2026-09-24 调查）

### 场景与棋具

1. 棋盘 `Ground.shader` 为 unlit，棋子 `StoneGloss.shader` 不采样阴影：阴影图每帧渲染却无人读取，画面上没有任何投影。
2. 棋盘是零厚度平面，周围是默认程序化天空盒，没有桌面，棋盘悬浮在虚空中。
3. 木纹 `GoBoardWood.png` 512²、饱和橙黄、细碎横纹；实际使用的 `ChessBoardTextureArray` 只有 1 级 mip、DXT5（多数 Android GPU 不原生支持），按世界坐标平铺。
4. 网格线为硬边不透明 quad，MSAA 关闭，线条与星位有锯齿；线色为纯灰黑。
5. 棋子是压扁的 Unity 内置球体（椭球），不是真实棋子的双凸透镜形；黑白子只有颜色和正弦“纹理”，没有蛤碁石条纹、没有环境光。
6. 落子动画从 y=30 落下后五次果冻弹跳和 ±10° 摇晃；正交俯视下看不到下落过程。提子瞬间消失，预览棋子无淡入淡出。
7. 坐标、手数、AI 胜率使用 legacy `TextMesh` + 内置字体；AI 推荐点为高饱和绿 + 黑描边。
8. 后处理：ACES 作用在 unlit 反照率上使木色偏暗偏移；Bloom 无意义；软阴影在 URP 资产中未开启。

### UI

1. 四套视觉语言并存：RPG 皮革/泼墨（主菜单、对局设置）、米色纸卡（确认框、用户信息、OGS、最近对局）、深色半透明 HUD（对局、复盘、局域网、加载）、薄荷绿（竖屏落子确认）。
2. 素材来自奇幻 RPG UI 包（药水、剑、盾、商店图标，泼墨按钮、泼溅进度条），与围棋主题冲突；没有任何九宫格；Unity 内置 Knob 被当作面板底图。
3. 92 种 Image 颜色、65 种文字颜色、代码中 60 处颜色字面量，没有色板。
4. 页面与弹窗开关、StateRoot 切换全部瞬切，唯一动效是对局提示条的透明度淡出。
5. 按钮多为默认 ColorTint，悬停几乎不可见；图标按钮无文字说明。
6. 胜率曲线为 1px 无接缝无抗锯齿 quad，饱和蓝/橙，无刻度、无 50% 基线，且每帧重建网格。
7. 对局 HUD 只有文字：没有棋子颜色标识、提子数、低时间状态。
8. 未处理 `Screen.safeArea`；各 prefab 的 CanvasScaler match 口径不统一。

### 外围

- App 图标为青色渐变 + 琥珀光 + 金线，风格偏“游戏化”；Splash 为 Unity 默认；主菜单为夜空天空盒。
- 只有一首 BGM 贯穿全部场景；没有 UI 音效；复盘场景无落子音效；音量全部硬编码，无淡入淡出。
- 冗余资产：未引用的 `FX_LootDrop_Blue`、`GoBoardWood.png`（旧）、TextureArray 未用层、`Road.mat` 丢失的噪声贴图、RPG UI 包。

## 性能预算

- 目标：Android 中端机（Medium 质量档）稳定 60fps；PC 不低于当前。
- 阴影：不渲染实时阴影贴图；棋子接触阴影为每颗一张面片（乘法混合），盘体落影在桌布 shader 中解析计算；不加 SSAO。
- 后处理：只保留 Color Adjustments、White Balance、Vignette；Tonemapping 覆盖为 None。
- 贴图：棋盘 2048（Android 平台覆盖 1024、ASTC）；桌面 1024 平铺；白子条纹 512；UI 主题贴图尽量小尺寸九宫格。
- Shader：棋盘/棋子/桌面均为单 pass 前向、仅主光 + SH 环境光；不使用额外灯光。
